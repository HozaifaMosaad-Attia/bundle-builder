# Bundle Builder

A React-based frontend take-home project. Users build a custom security system by selecting cameras, a monitoring plan, sensors, and accessories through a multi-step accordion builder, with a live review panel that updates as selections change.

## Tech Stack
- React
- Vite

## Getting Started

1. Clone the repository
```
git clone [https://github.com/HozaifaMosaad-Attia/bundle-builder]
```

2. Install dependencies
```
npm install
```

3. Run the development server
```
npm run dev
```

4. Open the local URL shown in the terminal (usually `http://localhost:5173`)

## Notes
- Product images and data are stored locally in `src/data.js` and `src/assets/`.
- Cart quantities persist automatically via `localStorage`.
